# 文件阿呜 · 桌面体验焕新

本轮目标是让「选择伙伴 → 投喂文件 → 看清结果」成为清楚、安静的日常操作。沿用 Electron、TypeScript、esbuild 与现有五款宠物，不引入 UI 框架或动画依赖。文件处理、安全边界和成长规则保持原有语义。

## 设计方向

界面以纯白为底，配新叶绿舞台、森林绿操作按钮和自然配色的宠物。标题与控件统一使用系统无衬线字体，常规中文标签直接说明用途。去掉英文装饰标题、宋体口号、伙伴编号和背景轨道；留白用于操作分组，不堆叠宣传文案。

| Skill | 本轮采用方式 |
| --- | --- |
| minimalist-ui | 保留平面布局和清晰层级；配色按用户最新反馈改为清新白绿，不继续使用灰色单色方案 |
| apple-design | 按下即时反馈、桌面宠物直接拖动、抽屉沿同一路径进入与退出、保留用户控制权 |
| better-ui | 按钮按下缩至 0.96，常用状态反馈控制在 150 ms 内；统一图标粗细、选中提示与减少动态适配 |
| building-native-ui | 借用原生控件、语义标签、键盘操作与可读状态原则；项目为 Electron，不迁移 Expo，不引入移动端运行流程 |

桌面操作密度优先于网页展示页的大段留白。抽屉属于点击打开的设置层，采用可反向的过渡，不增加拖拽关闭手势。宠物动画承担状态反馈和轻量互动，减少持续漂浮和多层循环，避免长期占用注意力。

## 布局与主要操作

- **首页与宠物馆**：顶栏提供两个独立页面，首页仅展示当前伙伴。舞台上的「更换伙伴」进入宠物馆，网格支持随伙伴数量向下扩展，搜索可按名字、性格和介绍筛选，提供清除、无结果及加载失败反馈。选择成功后返回首页；当前伙伴用徽标和语义状态标识。宠物馆内的切换和顶栏操作失败会直接显示在当前页面，可重试。
- **中央投喂舞台**：伙伴身份在左上，当前状态在右上。拖入文件时明确显示松手提示；舞台下方并列「选择文件」「选择文件夹」，旁边保留「试播动画」。试播不调用删除，也不增加成长统计。
- **结果与成长**：累计文件数、处理大小、虚拟体重和成长信息集中在舞台下方。实际操作结束后显示成功、部分成功、取消或失败结果；失败项保留原因，不仅靠动画或颜色表达。
- **桌面入口**：顶栏「桌面陪伴」控制显示和隐藏。关闭主窗口后，宠物继续留在桌面；退出需使用托盘、宠物面板或系统退出命令。

切换页面时清理追视和拖放状态；宠物馆与设置打开期间，隐藏的首页不接受文件投喂。投喂、试播或保存宠物选择期间暂时锁定页面导航，避免操作串到其他页面。

默认使用系统回收站，首页始终展示当前处理方式。选择永久删除后，每批仍经过系统确认；回收站失败不会自动转为永久删除。普通永久删除不等于安全擦除。只有成功处理的文件计入成长记录。

## 右侧设置抽屉

设置按钮和处理方式标签打开同一个抽屉，依次展示「文件处理」「桌面陪伴」「动态效果」。采用原生 `dialog`，背景暂不可操作，内容独立滚动，保存按钮固定在底部。面板距离窗口边缘 12 px，使用 20 px 圆角、半透明白色底与 28 px 背景模糊；外围只保留极轻的亮色和 2 px 模糊，不再用整页灰色遮罩。系统要求减少透明度或提高对比度时，切换为清晰的实色面板。

**保存语义明确分开：**宠物大小通过滑块即时保存，桌面宠物同步缩放；处理方式、显示偏好和减少动态需点击「保存偏好」才生效。关闭按钮、Escape 或点击抽屉外部会放弃未保存选项，但保留已即时保存的大小。关闭前等待进行中的大小写入，写入失败时在面板内显示提示。保存期间显示「正在保存」，避免重复提交。

抽屉从右侧出现、向右侧收起；减少动态时改为短淡入淡出。开关、单选和滑块保留标签与键盘能力，焦点有清晰轮廓，错误通过提示区域播报。

## 屏上宠物与品牌

桌面宠物支持点击回应、拖动身体移动、悬停查看统计和拖入文件投喂。右键打开贴近身体的大小面板，包含滑块、打开主窗口、隐藏及退出；macOS 可用 Control+单击，键盘可用 Shift+F10。减少动态时保留静态状态与方向提示，不依赖跳跃或晃动传达信息。

新版标志为嫩绿圆身阿呜：小圆耳与芽、森林绿微笑和杏桃脸颊。应用 SVG、PNG、macOS ICNS、Windows ICO 同源生成；菜单栏单独使用简化圆脸模板，由 SVG 渲染为抗锯齿的 16 px 和 32 px 资源，分别对应 1×/2× 显示。菜单栏不复用应用图标的腹部、手脚等细节，也不使用手写像素图。

## 本地体验

在源码仓库根目录运行，依赖已安装时无需重复 `npm ci`：

```sh
export FILE_MUNCHER_USER_DATA="$PWD/.local-data/design-refresh"
npm start
```

macOS 也可以在 Finder 双击 `scripts/start-design-preview.command`。启动器定位源码目录、执行构建，并固定使用上述独立配置；退出后可再次双击启动。当前体验版本由源码启动，不生成或覆盖已有安装包。

`npm start` 单次编译后启动真实 Electron 客户端，没有自动热更新；修改后正常退出再启动。独立配置只隔离偏好和成长记录，真实文件处理仍然生效。体验删除时使用自己创建的临时样本。

仅体验外观可运行 `npm run preview`，打开 `http://127.0.0.1:4173`。浏览器预览不会操作真实文件，不能替代桌面拖放或窗口验证。

建议体验顺序：进入宠物馆搜索、选择伙伴后回到首页试播 → 点击宠物 → 打开抽屉、修改并保存偏好 → 调整桌面大小 → 关闭主窗口后拖动与右键宠物 → 用临时样本验证回收站路径和结果反馈。
