## 验证边界

- 大小写敏感文件系统用例因本机临时盘不区分大小写跳过；实现已区分保护比较和真实路径去重。
- 身体拖动回归覆盖手势识别、真实光标位移计算和 IPC 会话结束；自动化注入鼠标事件未可靠驱动系统全局光标，不作为人工拖动手感验收。
- macOS 全屏文件追视结合拖拽专用 pasteboard 的新版本、文件类型与输入状态；观察器不读取文件路径或内容，不主动请求系统权限。策略测试与 renderer 合成消息不能代替所有源应用、跨屏和人工 Finder 拖放验收。
- 正常松手、Escape 和按键变化会结束全局注视；源应用自行结束拖拽、左键仍按住且没有按键变化时，缺少公开结束通知，可能持续注视到松手。未宣称实现完整的系统拖拽生命周期监听。
- 为捕获采样间的短 Escape，按键变化保守地结束全局注视；拖动中 `⌘+Tab` 切换应用也会暂停本次全局注视，下一次拖动恢复，窗口内文件拖放仍正常。
- Windows 文件追视仍限于窗口内的 `Files` 拖拽事件，未实现 Windows 全屏文件追视。
- Windows 安装、Explorer 人工拖放、回收站恢复和原生窗口行为尚未在 Windows 实机验证。
- Intel Mac 安装包已构建并校验，未在 Intel Mac 上运行。
- 没有 Developer ID 或 Windows 发布者证书；Mac 未公证，Windows 未签名。正式对外发布需要补齐证书流程。
- 普通永久删除不承诺数据无法恢复；目录删除中途失败可能部分完成，界面会明确提示。

## 复验

```sh
npm run check
npm run test:renderer
npm run test:desktop
```

从 DMG 复制应用后，可设置 `FILE_MUNCHER_EXECUTABLE` 为应用内 `Contents/MacOS/file muncher` 的绝对路径，再运行 `node scripts/smoke.mjs` 复验打包应用。该变量只控制测试启动路径，测试文件与配置仍使用独立临时目录。

源码、配置、图标、测试和说明纳入本地 Git 管理；依赖、安装包、测试产物与本地配置目录均被忽略。远端仓库与后续推送由维护者另行配置。
